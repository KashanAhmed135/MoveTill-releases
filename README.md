# MoveTill updates

Signed update packages for MoveTill POS. Shops' main PCs download them from here (Settings > Update).

- Each `MoveTill-x.y.z.mtupdate` is signed by the developer. The app checks the signature and refuses anything changed or fake.
- `latest.json` points to the newest package.
- No source code, keys or shop data are here. A license key is still needed to use MoveTill beyond the trial.
